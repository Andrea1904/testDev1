public double CalcularDistanciaRecorrida(List<EventoGPS> eventos)
{
    double distanciaTotal = 0;

    for (int i = 1; i < eventos.Count; i++)
    {
        var anterior = eventos[i - 1];
        var actual = eventos[i];
        distanciaTotal += DistanciaHaversine(anterior.Lat, anterior.Lng, actual.Lat, actual.Lng);
    }

    return distanciaTotal;
}
Este código suma distancia recorrida incluso cuando el vehículo está parqueado (por el ruido natural del sensor GPS, que hace que la posición "salte" unos metros aunque el vehículo no se mueva). a) Corrige el código, b) ¿qué caso límite queda sin cubrir con tu corrección? public List<ReporteVehiculo> GenerarReporteMensual(List<int> vehiculoIds)
